# vurko-assets

Public CDN for VURKO marketing assets.

Product-card videos for TikTok Shop Vietnam are attached as **release assets** —
the Miaoshou (妙手) ERP `mainImgVideoUrl` field requires a publicly fetchable URL
whose path ends in `.mp4`, which is what this repo provides.

Everything here is material that is published to TikTok anyway. No credentials,
no business data.
